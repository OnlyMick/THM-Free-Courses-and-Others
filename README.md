# Free Cybersecurity Roadmap (TryHackMe & Others)

This repository is a sequential learning path designed to take you from absolute zero to mastering the fundamentals, leveraging the best free-tier resources available across multiple platforms.

## Phase 0: Onboarding & Setup
Learn how to use the platform.
*Note: THM only allows 1 hour on their VMs. It is strongly recommended that you download VMware with Kali Linux or Parrot OS.*
*Remember: Take notes, don't try to do everything in your head.*
